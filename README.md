# Ventro Bank Website

Independent static website for Ventro Bank.

- No Base44 runtime or dependency
- No website authentication, payments, database, or support form
- Designed for GitHub Pages and future custom-domain deployment
- Android Play URL is centralized in `config.js`
- Official community: https://discord.gg/dJ8aGdGapq

Ventro Bank is fictional and intended for LARP, roleplay, and entertainment. It does not provide real banking or financial services.
